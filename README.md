# RATER Challenge Solution

This repository contains the modeling code, experiments, and supporting materials for my RATER Challenge project.

## Final solution

The final solution is documented in **[RaterSolution_IoannisMeintanis.pdf](RaterSolution_IoannisMeintanis.pdf)**. Start here for the project's final approach and results.

## Repository contents

- [`RaterSolution_IoannisMeintanis.pdf`](RaterSolution_IoannisMeintanis.pdf) - final solution document.
- [`src/`](src/) - project source code, including models, datasets, metrics, and utilities.
- [`scripts/`](scripts/) - training, inference, and post-processing scripts.
- [`nbs/`](nbs/) - experiment and analysis notebooks.
- [`solutions/`](solutions/) - reference implementations and configurations for Feedback Prize solutions.
- [`det_utils/`](det_utils/) - supporting detection and metric utilities.
- [`Files/Resources/`](Files/Resources/) - supporting project resources.
- [`environment.yml`](environment.yml) and [`requirements.txt`](requirements.txt) - environment and package dependency specifications.

## Getting started

Review the final solution document and the relevant experiment notebook or script before running an experiment. Local competition data, checkpoints, and generated artifacts may be needed; see [`.gitignore`](.gitignore) for paths and file types that are not tracked.
